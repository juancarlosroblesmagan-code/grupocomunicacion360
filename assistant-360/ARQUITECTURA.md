# Arquitectura

- `A360_Plugin`: ciclo de vida, recursos y administración.
- `A360_REST`: sesión y consulta pública.
- `A360_Rate_Limiter`: límites y reserva de presupuesto.
- `A360_Knowledge`: recuperación local de documentos aprobados.
- `A360_OpenAI_Client`: Responses API desde servidor.
- `A360_Stats`: métricas agregadas sin mensajes.

No modifica el tema, WPBakery, núcleo, SEO ni formularios.
